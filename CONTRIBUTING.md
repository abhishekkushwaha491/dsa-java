# Contributing

Thank you for your interest in improving this repository.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Add or improve code, tests, or documentation.
4. Run the test suite.
5. Open a pull request with a clear description.

## Code quality expectations

- Write clean, readable Java code.
- Include comments where helpful.
- Explain time and space complexity.
- Mention edge cases in documentation or code comments.
- Add tests for bug fixes and new features.

## Commit guidelines

Use clear and descriptive commit messages.
Examples:
- `Add binary search implementation with tests`
- `Improve linked list edge case handling`
- `Document stack complexity and usage`

## Questions

Open an issue if you have questions or suggestions.
